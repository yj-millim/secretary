# 🤖 김비서 (Kim Secretary)

> AI 기반 일일 업무 브리핑 및 대시보드 자동화 시스템

## 개요

**김비서**는 Claude AI의 스킬 기능을 활용하여 데이터 파일을 읽고 분석해 일일 업무 브리핑을 제공하고 대시보드를 자동으로 업데이트하는 시스템입니다.

- 📋 **일일 브리핑**: 오늘 해야 할 일, 회의, 긴급 항목 자동 정리
- 📊 **실시간 대시보드**: CSV 데이터 파일 자동 반영
- 🎯 **우선순위 정렬**: 높음/보통/낮음 우선순위 기반 정렬
- ⚠️ **긴급 알림**: 마감 임박 작업 자동 감지

## 데이터 파일 설명

### 📋 업무목록.csv
- **컬럼**: 업무, 우선순위, 상태, 담당자, 마감일, 카테고리
- **용도**: 일일 브리핑의 작업 목록 생성
- **날짜 형식**: YYYY-MM-DD

### 📅 주간일정.txt
- **형식**: 자유로운 텍스트
- **용도**: 오늘의 회의/일정 추출
- **예시**: 각 요일별 일정 나열

### 📊 프로젝트현황.csv
- **컬럼**: 프로젝트명, 진행률, 상태, 담당자, 시작일, 마감일, 예산, 집행
- **용도**: 대시보드 프로젝트 진행도 표시
- **진행률**: 0~100 (백분율)

### 💰 매출데이터.csv
- **컬럼**: 날짜, 제품, 카테고리, 수량, 단가, 매출액, 지역
- **용도**: 오늘의 판매액 집계, 차트 생성
- **날짜 형식**: YYYY-MM-DD

### 📝 회의록.txt
- **형식**: 자유로운 텍스트 (구분선 권장)
- **용도**: 최근 회의 내용 참고
- **브리핑에 포함**: 최근 결정사항 요약

## 스킬 작동 원리

### 📌 `/김비서` 실행 시 순서

1. **데이터 읽기** 📂
   - 김비서-데이터 폴더의 모든 파일 읽음
   - CSV 파싱, TXT 추출

2. **데이터 분석** 🔍
   - 현재 날짜와 비교
   - 마감일이 오늘 또는 과거인 작업 필터링
   - 우선순위별 정렬

3. **계산 및 통계** 📈
   - 오늘의 총 매출 합산
   - 활성 프로젝트 수 계산
   - 작업 완료율 산출

4. **브리핑 생성** ✍️
   - 마크다운 형식으로 정렬
   - 우선순위별 표시
   - 시각적 이모지 활용

5. **대시보드 업데이트** 🎨
   - dashboard.html 데이터 반영
   - 최신 정보 실시간 표시

## 주요 기능

### ⚠️ 긴급 확인
- 높은 우선순위 + 마감 임박 작업 우선 표시
- 오늘 또는 어제 마감 작업 강조

### 📌 오늘의 할 일
- 마감일이 오늘인 모든 미완료 작업
- 우선순위별 정렬 (높음→보통→낮음)
- 담당자와 카테고리 정보 포함

### 📅 일정 확인
- 오늘 날짜의 모든 회의/일정
- 시간 정보 포함

### 📊 핵심 지표
- **진행 중인 프로젝트**: 활성 프로젝트 수
- **작업 완료율**: (완료/전체) × 100%
- **오늘 매출**: 오늘의 총 판매액
- **판매 수량**: 오늘 판매 건수

## 트러블슈팅

### Q: 브리핑이 빈 상태로 나옴
- 데이터 파일 확인 (UTF-8 인코딩, 올바른 경로)
- 날짜 형식 확인 (YYYY-MM-DD)
- 파일명 정확성 확인

### Q: 대시보드가 업데이트 안 됨
- HTML 파일의 데이터 바인딩 점검
- 브라우저 캐시 제거
- 파일 경로 확인

### Q: GitHub 푸시 실패
- 토큰 유효성 확인
- .gitignore 작동 확인 (`git status`)
- 네트워크 연결 확인
